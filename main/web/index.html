      Channel Mapping

      Which physical receiver pin backs each function. Wiggle a stick or flip a switch and watch the numbers below to identify its pin, then assign it below.

      Outputs

      Which servo_out pin on the board each function drives. Picking a pin that's already taken swaps the two. Calibration below stays with the function, so it follows the servo to its new pin.

      Live pulse width updates as the RC receiver moves. "Set as Min/Max" fills in the field from the current live value; Save commits it.

      Control Tests

      Direction: sends the autopilot's full roll/pitch command for 4 seconds, no IMU involved. Check each surface moves the way the button says (e.g. Roll right: right aileron up, left down). If one is backwards, fix it with Reversed in Outputs.

      Level: runs the real autopilot (IMU + PID) trying to hold level for 15 seconds. Tilt the board: the surfaces should push it back toward level (dip the right wing → it should roll left; nose down → it should pull up). Do the direction tests first.

      Autonomous Trim

      The neutral each surface is held around when autonomous flight takes over (manual flight uses your transmitter trim directly). Trim the plane on the transmitter until it flies level hands-off, land, enter setup mode, let go of the sticks, then Capture. Limited to ±200 µs from 1500.

      Motors

      ESC1/ESC2 always receive the identical throttle command today -- there's no differential-thrust mixing yet, so Left/Right is just a label for later.

      Remove propellers first. Test spins only that ESC's motor at 15% of its calibrated range for 1 second (the other ESC is held off), so you can see which physical motor is which.
